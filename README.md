# Customer Churn Analysis Dashboard

A Power BI dashboard analyzing customer churn patterns, built end-to-end from raw data to interactive insights.

# Overview

This project explores customer churn behavior using a publicly available dataset. It covers the full pipeline — from raw data cleaning and transformation to a fully interactive Power BI dashboard — to help identify key drivers of churn and support data-driven retention strategies.

# Project Workflow
Data Sourcing — Raw dataset sourced from a public/open data repository.
Data Cleaning & ETL — Performed in SQL Server Management Studio (SSMS):
Handled missing/null values
Standardized data types and formats
Removed duplicates and inconsistent records
Transformed raw tables into analysis-ready structures
Data Modeling — Structured cleaned data into a relational model suitable for reporting (fact/dimension tables, relationships).
Dashboard Development — Built in Power BI, including:
DAX measures for churn rate, retention rate, and key KPIs
Interactive filters and slicers (e.g., tenure, contract type, demographics)
Visual breakdowns of churn by customer segment
Tech Stack
Tool	Purpose
SQL Server Management Studio (SSMS)	Data cleaning, transformation, and ETL
Power BI	Data modeling, DAX calculations, dashboard/visualization
